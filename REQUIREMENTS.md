# Системные требования

AETHER Ambient Studio — нативное Windows-приложение (Python + WebView2), а не браузерная страница.
Звук синтезируется на CPU в реальном времени, поэтому главное ограничение — **процессор и аудиобуфер**, а не видеокарта.

## Минимальные требования

| Компонент | Минимум |
|---|---|
| ОС | Windows 10 (1809+) или Windows 11, x64 |
| Процессор | 2 ядра, 1.8 ГГц (например, Intel Celeron, AMD Athlon) |
| Оперативная память | 4 ГБ (3.5 ГБ фактически доступно уже работают) |
| Диск | ~120 МБ свободно (onefile распаковывается во временную папку) |
| Видео | любой адаптер с поддержкой DirectX 11 |
| WebView2 Runtime | обязателен: поставляется с Windows 11, в Windows 10 — скачивается при установке |
| Экран | рабочего стола **1280×800** минимум (окно не меньше 1160×740) |
| Звук | любое устройство вывода, без ASIO |

**Проверено на реальной машине этой планки:** AMD Athlon Silver 3050U (2 ядра / 2 потока, 2.3 ГГц), 3.4 ГБ ОЗУ, AMD Radeon Graphics (512 МБ), WebView2 158.
Именно на ней эко-режим и был спроектирован.

На минимальной конфигурации:

- эко-режим включается автоматически (`ЭКО` в шапке, клавиша `E`);
- живое воспроизведение обходится **258 источниками** вместо 1032;
- 16 тактов играют и экспортируются, 32 такта будут заметно тяжелее;
- **экспорт WAV 16 тактов занимает порядка 30–90 секунд** — это нормально и выполняется офлайн;
- piano roll скрывается автоматически при высоте окна меньше 760 px, overview — меньше 740 px.

## Рекомендуемые требования

| Компонент | Рекомендация |
|---|---|
| ОС | Windows 11 x64 |
| Процессор | 4 ядра, 2.5 ГГц+ (Ryzen 3 5300U / Intel i3-11xxx и выше) |
| Оперативная память | 8 ГБ |
| Диск | SSD, 200 МБ свободно |
| Видео | встроенная графика с 1 ГБ видеопамяти |
| Экран | 1920×1080, масштаб 100–125 %, окно 1560×960 |
| WebView2 Runtime | 120+ (обычно уже установлен) |
| Звук | любое устройство вывода |

На рекомендованной конфигурации:

- HQ-режим держит полный тембр пиано (6 партиалов + корпус + удар);
- 32 такта генерируются и играют без пропусков;
- экспорт 16 тактов — около **25 секунд**, 32 такта — до минуты.

## Комфортные требования

| Компонент | |
|---|---|
| Процессор | 6–8 ядер, 3 ГГц+ |
| Оперативная память | 16 ГБ |
| Экран | 2560×1440 и выше |

Подходит для больших сессий на 32 такта, нескольких дорожек в solo, рендеров подряд и параллельной работы в других приложениях.

## Чего точно не хватает

- **Windows 7/8** — не поддерживаются: нужен WebView2, современные WinRT-зависимости и `pythonnet`.
- **32-битная Windows** — не поддерживается, сборка x64.
- **macOS / Linux** — текущие exe только под Windows; логика кроссплатформенная, но окно и звук идут через WebView2.
- **Без WebView2 Runtime** приложение не запустится. Установка: [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

## Куда не класть exe

Путь запуска должен **не содержать кириллицу**. Встроенный Python.NET не загружает нативные сборки из путей с русскими буквами, поэтому приложение стартует из ASCII-папки.

- Можно: `C:\AETHER`, `C:\Users\Public\AetherAmbientStudio`, `D:\Apps\AETHER`.
- Нельзя: `C:\Users\Иван\Downloads`, `D:\Музыка\AETHER`.
- Если Windows показывает предупреждение SmartScreen, нажмите «Подробнее → Выполнить всё равно».

## Как снизить нагрузку, если ПК слабее рекомендуемого

1. Включить **ЭКО** (клавиша `E`) — главный фактор стабильности звука.
2. Выбрать **8 или 16 тактов** вместо 32.
3. Закрыть браузер и тяжёлые приложения во время воспроизведения.
4. Не отключать питание от сети: на батарее Windows сбрасывает частоту процессора.
5. Экспортировать WAV, а не слушать в HQ во время рендера — экспорт всегда идёт офлайн и не конкурирует за реальное время.
