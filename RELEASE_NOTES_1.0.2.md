# AETHER Ambient Studio 1.0.2 — system requirements

This release documents the hardware support matrix and makes the repository self-explanatory for new users. The application binary is unchanged from 1.0.1.

## Added

- `REQUIREMENTS.md`: minimum, recommended and comfortable tiers, verified test stands, unsupported configurations, and tips for weak PCs.
- A **System requirements** section in `README.md` with a compact table and the real numbers from the 2-core / 3.4 GB test machine.
- Repository homepage now points to the latest release.

## Support matrix at a glance

| | Minimum | Recommended |
|---|---|---|
| OS | Windows 10 1809+ / 11, x64 | Windows 11 x64 |
| CPU | 2 cores, 1.8 GHz | 4 cores, 2.5 GHz+ |
| RAM | 4 GB | 8 GB |
| Disk | ~120 MB | SSD, 200 MB |
| GPU | DirectX 11 | integrated, 1 GB |
| WebView2 | **required** | 120+ |
| Desktop | 1280×800 | 1920×1080 |

ECO mode enables automatically on 2–4 cores and 4 GB or less: 258 live sources instead of 1032. WAV export stays HQ.

Not supported: Windows 7/8, 32-bit Windows, macOS/Linux in the current builds, and launch paths containing Cyrillic characters.
