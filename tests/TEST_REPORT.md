## Volume Alpha 2011 / Minecraft

Volume Alpha переделан после анализа девяти референсов:

- фетровое пиано с hammer-транзиентом, независимым затуханием шести партиалов и лёгкой негармоничностью;
- 116 и 110 нот в двух демо — разреженные фразы вместо плотных арпеджио;
- 4-барная гармония, мягкие maj7/add9/sus-аккорды;
- тёплый бас, тихие пэды/струнные, редкая музыкальная шкатулка, кассетная пыль;
- мастер-цепочка: low-shelf, срез верха, мягкая компрессия, аккуратное стерео;
- убран прежний высокочастотный «воздух», который делал звук синтетическим.

## Алгоритм

Кнопка «АЛГОРИТМ» показывает реальную трассу текущего проекта: seed, hash, ключ, BPM, аккорды, прогрессию, сигнатурные инструменты, плотность, время генерации и последний рендер.

Алгоритм:

1. `seed` → FNV-1a hash → `mulberry32` PRNG;
2. профиль стиля: 8 сигнатурных инструментов, лад, BPM, эффекты;
3. тональность и прогрессия по ступеням лада;
4. форма intro / build / body / outro;
5. восемь ролей (атмосфера, пэд, клавиши, бас, колокола, струнные, лид, пыль);
6. вероятностные генераторы нот: позиции, длительности, регистр, velocity, паузы;
7. Web Audio-планирование и тот же граф для офлайн-экспорта;
8. кэш нот и пропуск беззвучных дорожек при рендере.

Проверка: 200 проектов подряд (5 стилей, 8/16/32 такта) — **0 ошибок**, 39 895 нот.  
Кнопка «Случайный эмбиент» и `Shift+G` выбирают случайный стиль, BPM и seed.

### Pipeline как исполняемая последовательность

- Под генератором видны шесть шагов: `01 SEED → 02 KEY → 03 CHORDS → 04 FORM → 05 ROLES → 06 MIX` с фактическими значениями.
- Кнопка `▶ ВЫПОЛНИТЬ` проходит шаги по порядку и после последнего запускает генерацию.
- В окне «Алгоритм» есть кнопки **«Выполнить последовательность»** и **«20 сек · Wet Hands proof»**.
- Проверено: 6 шагов, после выполнения обновлены seed/key/chords/form/roles/mix, проект валиден, 0 ошибок.

## 20 секунд из Volume Alpha

Кнопка **PROOF · 20 сек · Wet Hands** загружает отдельный проект `Wet Hands · 20 sec`:

- источник: `C418 — Wet Hands (Volume Alpha, 2011)`, фрагмент `00:00–00:20`;
- 129 нот, транскрипция `piano_transcription_inference` (Note_pedal CRNN);
- 8 регистровых дорожек, 8 тактов × 96 BPM = 20.0 секунд;
- старты нот пересчитаны из исходных секунд, поэтому тайминг фрагмента сохранён;

## Ограничение окружения

В имени профиля `C:\Users\Я` есть кириллица. Python.NET/WebView2 не загружает нативные сборки из такого пути, поэтому exe размещён в ASCII-пути `C:\Users\Public\AetherAmbientStudio`. Портативный ZIP следует распаковывать в путь без кириллицы, например `C:\AETHER`.
